# 藍星科技開通網

藍星科技的授權碼建立與 LINE 官方帳號開通入口。

- 僅接受 6 位數字驗證碼
- 驗證碼不寫入網址或瀏覽器儲存空間
- 複製後直接開啟藍星科技 LINE 官方帳號
- 管理端可選擇 15、30、90、365 天或自訂期限建立授權碼
- WBS、GitHub 與 SD 影片權限預設關閉，只有管理者建立授權碼時可選擇開通
- SD 影片採積分制，每秒扣除 9 積分，單支最長 15 秒
- SD 積分以 1 元兌 1 積分儲值，單次最低新台幣 36 元
- 管理者查詢已開通帳號後，可直接累加 SD 積分並啟用 SD 影片；不需重新授權，也不會改變原使用期限
- 管理者可查看每位 LINE 用戶今天的 IMAGE2 已用與剩餘額度
- 管理者可重置今天全部用戶或指定單一用戶的做圖額度；操作前會再次確認
- 額度管理以 LINE 顯示名稱為主，遮罩尾碼只用於辨識同名帳號；每位用戶旁都有單獨重置按鈕
- 舊開通資料若缺少 LINE ID，LBOT1 會從既有隔離用戶資料自動回填，恢復 SD 積分加值
- 做圖或故事版任務執行中時禁止重置，避免已保留額度與實際成品不一致
- 管理密碼可在成功建立授權碼後加密記住於目前瀏覽器，也可隨時清除

驗證碼仍由既有藍星科技後端產生與驗證。此靜態網站與 GitHub 儲存庫不包含 LINE 憑證、管理密碼或驗證碼資料。
