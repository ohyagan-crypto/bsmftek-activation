# BSMFTEK 開通網

BSMFTEK 的授權碼建立與 LINE 官方帳號開通入口。

- 僅接受 6 位數字驗證碼
- 驗證碼不寫入網址或瀏覽器儲存空間
- 複製後直接開啟 BSMFTEK LINE 官方帳號
- 管理端可選擇 15、30、90、365 天或自訂期限建立授權碼
- WBS、GitHub 與 SD 影片權限預設關閉，只有管理者建立授權碼時可選擇開通
- SD 影片可設定獨立積分，成功交付影片後每筆扣除 1 點
- 管理密碼可在成功建立授權碼後加密記住於目前瀏覽器，也可隨時清除

驗證碼仍由既有 BSMFTEK 後端產生與驗證。此靜態網站與 GitHub 儲存庫不包含 LINE 憑證、管理密碼或驗證碼資料。
